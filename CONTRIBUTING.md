# Contributing to Web2APK Image Studio

Thanks for considering a contribution!

## Getting started

- Discuss larger changes through an issue first.
- Make changes in a feature branch and open a pull request.
- Keep claims in documentation aligned with functionality that has actually been tested.
- Run `npm test` and `npm run build` before requesting review when the app source is installed.
- Never commit API keys, credentials, private designs, or assets that you cannot redistribute.

## Project scope

The first release targets client-side image processing and export of Android packaging configuration. APK compilation is not part of the first release. Contributions toward reproducible Android builds should include tests, security considerations, and documentation.

## Reporting issues

Describe your operating system, browser, reproduction steps, and expected versus actual behavior. Do not disclose private URLs or secrets in issue reports.
